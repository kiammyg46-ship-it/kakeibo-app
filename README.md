# 家計簿アプリ

Node.js + MySQL を使用して作成した家計簿アプリです。

## 主な機能
- 支出追加
- 一覧表示
- 編集
- 削除
- 合計金額表示
- カテゴリ検索
- 月選択機能
- 月別合計表示
- 円グラフ表示

## 使用技術
- Node.js
- Express
- MySQL
- HTML
- CSS
- JavaScript
